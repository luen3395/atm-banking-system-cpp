# ATM Banking System in C++

## Overview
This project is a console-based ATM banking system developed in C++ as a final project for IT217 Programming Language at Washington University of Science and Technology.

The application authenticates users using PIN codes stored in an external file and provides common ATM operations such as deposits, withdrawals, balance inquiries, and account summary generation.

## Features
- User authentication with PIN verification
- Deposit funds
- Withdraw funds with insufficient balance protection
- Check account balance
- Generate account summary in a text file
- Menu-driven user interface

## Technologies Used
- C++
- File Input/Output
- Arrays
- Functions
- Loops and Conditional Statements

## Files Included
- `Arguet_FP.cpp` – Main source code
- `aprovedPinCodes.txt` – List of authorized PIN codes
- `Argueta_FP.txt` – Output account summary generated after execution

## How to Compile and Run

### Compile
g++ Arguet_FP.cpp -o atm

### Run
./atm
